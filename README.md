# Mandalina Zıpla 🍊

Yapraktan yaprağa zıplayan bir mandalina. Telefon tarayıcısında oynanır, kurulum gerektirmez.

**Oyna:** https://muratbaskicioglu.github.io/mandalina-zipla/

- Ekranın sol ya da sağ yarısına basılı tut, mandalina o yöne gider (bilgisayarda ←/→).
- Meyve suyu damlaları +10 m. Kuşlara çarpma, kuru yapraklar kırılır, yaylar seni fırlatır.
